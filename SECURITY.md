# Security Policy

## Supported versions

DevPilot is pre-alpha and has no supported production release. Security fixes are applied to the default branch.

## Reporting a vulnerability

Do not open a public issue. Use GitHub's private vulnerability reporting feature for this repository. If that feature is unavailable, contact the repository maintainers privately through their published GitHub contact details.

Include impact, affected component, reproduction steps, and any suggested mitigation. Do not access data you do not own, degrade services, or publish details before maintainers have had a reasonable opportunity to respond.

## Security posture

No current component is approved to execute untrusted repository code. The architectural security requirements are documented in `docs/security/01-threat-model.md`. Phase 0 is a foundation and must not be treated as a production-ready release.
